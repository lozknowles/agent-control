# v4.14 RC1 release claim audit

Scope: proposed v4.14 changes, release notes/draft, qualification/installation/security documents, new dashboard styling and the delivered videos. Inherited older product claims are not relabelled as newly qualified. No GitHub release was created.

| Claim | Evidence | Qualification | Limitation |
| --- | --- | --- | --- |
| Missing GPU tooling no longer crashes discovery | Red/green process and GPU cases; two pristine installs | Bounded CPU-only installation path | Five GPU failure states; not all optional integrations on all OSes |
| Doctor reports core readiness | Six tests, two VM doctor receipts | Prerequisite check | No runtime/model/authentication qualification |
| Clean install works | Two restored pristine snapshots, FIRST_RUN and approved Job receipts | Recorded Ubuntu/runtime revision | Not universal out-of-box OS provisioning |
| Upgrade and rollback work | Genuine disposable systemd stages with state/config/ledger checks | Legacy observation Jobs | New experimental format downgrade unqualified |
| Semantic tools improve execution | 4/5 verified internal model tasks, 0 parser/translation failures | Experimental integrated result | No external benchmark, no universal parity, complete service path not qualified |
| Repair is bounded | Frozen 150-case comparison, 10 baseline false repairs removed | Experimental corpus safety | Not arbitrary intent recovery or a universal zero-failure guarantee |
| Numbered writes are protected | 19/21 broader cases, all contaminated writes blocked | Experimental | Two legitimate-content false positives; no arbitrary patch/atomic multi-file claim |
| No-progress recovery exists | 41 offline cases, physical warning/replan/escalation/termination | Experimental | Scripted recovery is not autonomous problem solving |
| Diagnostics match events | 56 physical dispatch lifecycle pairs | Narrow reconciliation | Separate from prior 47/264 evaluations; observer attribution limitation retained |
| Security findings reviewed | 98 source-linked manual dispositions and two browser fixes | Bounded finding review | Native needs-validation records retained; 12/12 PARTIAL coverage |
| Multi-host operation works | Standard managed-node inspection across two Linux hosts | Bounded read-only capability | Pixel identity unverified; no new Android/Windows claim |
| Stable colours identify Jobs | Twelve-slot hash library, identity tests, concurrent live records | Stable mapping | Collisions possible; text ID and status required |
| Video is genuine live evidence | Recorder start/end and runtime event timestamps | Bounded unsigned visual evidence | Controlled HTTP versus Qwen labelled; two model parts disclosed |
| Local inference resources measured | Actual HTTP usage fields and Job times | Provider-reported accounting | Canonical adapter unattested; no dollar-equivalent or energy estimate |
| Final artifact is reproducible/tested | Two archives, clean extraction/install/typecheck/Job and exact-commit check | Bound in external seal | No publication or production deployment implied |

Forbidden unsupported claims remain absent from the proposed release scope: AutomationBench qualification, AWS cost reproduction, universal model parity, universal Linux support, atomic multi-file operations and signed video. The headline classification is EXPERIMENTAL, not READY_FOR_RELEASE.
