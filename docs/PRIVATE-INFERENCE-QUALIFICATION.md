# Private inference qualification harness

The product code continues to use the provider-neutral OpenAI-compatible client. These opt-in scripts run physical qualification against an operator-provided private endpoint; they do not enable production routing or deploy a service.

- `qualification-runtime-process.mjs start|status|stop SETTINGS.json`: run on the device. Starts a loopback-only llama-server process, captures its launch arguments and process-cold health timing, and signals only a matching recorded process identity. Configuration owns model path, alias, binary, port and context. The current measurement profile is CPU, four threads, one slot and reasoning off.
- `benchmark-private-inference.py`: runs the supplied frozen suite against the real endpoint. Records all prompts, streaming events, outputs, runtime token counts/timings and controller latency separately. SSH reads physical RAM/RSS. The battery/thermal fields explicitly remain unavailable in this profile. Coding checks use Linux bubblewrap and prlimit on the controller, not the device.
- `qualify-private-inference.ts SETTINGS.json`: starts an isolated Agent Control dashboard using normal Work Parcels, saved jobs, repository review, verification, routing, token accounting and product transcripts. A real health/model-inventory preflight is mandatory. A small committed arithmetic fixture deliberately contains a subtraction defect. Planning chooses the existing review job deterministically; the real provider must produce the finding. The route is experimental and excluded from ordinary execution. The operator token is passed through `AGENT_CONTROL_QUALIFICATION_OPERATOR_TOKEN`.
- `record-private-inference-http.py`: loopback-only transparent evidence proxy. Saves complete request/response bodies, status and elapsed time. It does not retry, invent model output or log authentication headers.
- `record-private-inference.mjs STATE_DIR`: uses Playwright and Chromium to authenticate, submit the initiating prompt through the normal dashboard, show live views and open the complete transcript. It records continuous video and screenshots. `cancelOnReconnect` selects the real dashboard Cancel Run button during an observed reconnect backoff.
- `run-private-inference-qualification.py SETTINGS.json`: owns the temporary dashboard/proxy/browser processes and passes a random operator token only through child-process environments. Requires a separately established SSH loopback forward on port 19483. It records the proxy on 19482; the dashboard port is configurable. With `disconnectTunnel: true`, it checks the PID/start-time files `tunnel.pid` and `tunnel.start` beside the settings file, then closes that owned forward after successful preflight. It does not signal arbitrary SSH processes.

Use a fresh state directory for every attempt. Do not replace a failed attempt with a later result. Preflight must prove the physical model alias and the independently verified file hash must be recorded in settings. Endpoint inventory alone is not physical execution proof: retain device process/runtime logs at the actual invocation time.

Dependencies: the repository's TypeScript runtime and Playwright installation; controller Python 3, bubblewrap, prlimit and Chromium; enrolled SSH credentials supplied as a file reference; a separately built compatible device runtime. No credential or model weight belongs in the repository.

For the Pixel experiment, see the dated qualification evidence and reproduction record. That evidence distinguishes the five-task raw text suite at 2,048 context tokens from governed repository review at 4,096 context tokens. It also distinguishes source release, the isolated qualification dashboard and existing deployed services.
