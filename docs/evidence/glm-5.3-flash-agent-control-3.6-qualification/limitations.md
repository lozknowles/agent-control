# Limitations

- This is one frozen repository task with two comparable stochastic runs, not a population estimate.
- The first Codex streaming-provider preflight failed before model output. A non-streaming typed Responses runner was frozen before scored-lane output; the amendment and failed attempt are retained.
- A typed-runner pilot made three read-only model calls before an EOF-range harness defect aborted it. The runner was corrected before Lane A; all pilot evidence and both facts are retained.
- Input tokens were reported but could not be hard-capped. Equality was enforced through identical request, retry, wall-clock, output-token, tool-output, test, filesystem, network, and change limits.
- Provider defaults were used for temperature, top-p, and reasoning effort. They are recorded as unknown/default, not assumed values.
- Lane B used one coherent child Contract so the model received the identical two-stage task as Lane A. The baton governed authority and lifecycle but did not replace the complete debt brief with a summary.
- The governed baton records one active primary model worker. The frozen envelope's maximum of zero parallel workers means zero additional/subagent workers; no calls overlapped.
- Neither run reached implementation. The experiment therefore says nothing positive about GLM's coding ability on a successfully scoped task.
- The independent 628-test passes establish unchanged-baseline health and containment only.
- The optional `gpt-5.6-luna` control was `NOT_RUN`; no result is estimated.
- No production service, live Agent Control deployment, release branch, main branch, tag, or canonical documentation was changed.
