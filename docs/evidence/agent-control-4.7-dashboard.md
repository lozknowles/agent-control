# Agent Control 4.7 paused dashboard recordings

Two fresh recordings repeat the accepted 4.6.1 desktop/mobile journey on the 4.7 release source: submit a real governed repository-review job, select an active process, watch fresh session output and its running timer, inspect per-call and total Usage, then open and download readable input/output history and reopen it after refresh.

Each Usage view is held for at least two seconds. The work uses synthetic repository content and an existing subscription-included worker; the execution, usage and state transitions are real. Cached input is reported exactly as observed, including zero, and is a subset of input. Unknown monetary cost is not zero cost.

[Recordings, SHA-256 manifest and redacted qualification summary](https://github.com/lozknowles/agent-control-qualification-evidence/releases/tag/agent-control-4.7.0-dashboard).

The desktop viewport is 1920 × 1080 and mobile viewport is 390 × 844. The latter is browser emulation, not a physical phone or voice qualification. Neither recording claims spoken completion. The release asset manifest gives the exact capture commit, run/session identifiers, native/displayed token reconciliation, output changes, timer observations, durations and minimum Usage dwell.

The heavy recordings are intentionally excluded from this source tree and normal source pulls. Earlier 4.6.1 videos are preserved with their original names and hashes, not relabelled as 4.7.
