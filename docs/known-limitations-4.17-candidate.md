# Agent Control 4.17 candidate limitations

This candidate register supplements the historical public-release ledger. It does not rewrite earlier evidence.

| ID | Status | Limitation |
|---|---|---|
| AC-4.17-LIM-01 | BLOCKER | Automatic evidence has no registered physical capture provider and required-capture policy cannot yet prevent the operational Job action before dispatch. |
| AC-4.17-LIM-02 | UNSUPPORTED | The qualified Qwen Image 2.1 adapter remains IMG01 generation-only. IMG02–IMG08 are rejected before provider execution. |
| AC-4.17-LIM-03 | INCOMPLETE | Only one legitimately available image provider was found, so the reusable benchmark contract is tested but no cross-provider physical comparison is claimed. |
| AC-4.17-LIM-04 | BLOCKED | Colab A100 was disabled for the authenticated account. T4 was available but was not substituted for the requested A100 route. |
| AC-4.17-LIM-05 | QUALIFIED_WITH_LIMITATIONS | Qwen timing covers one frozen 768x768 request on one 16 GB GPU. The 1.1-second same-seed repeat was provider node-cache reuse, not warm inference. |
| AC-4.17-LIM-06 | QUALIFIED_WITH_LIMITATIONS | The Blender result qualifies one bounded semantic procedure, not general Blender autonomy. Physical replay cancellation was inherited from 4.16 rather than repeated for the learned procedure. |
| AC-4.17-LIM-07 | NOT_QUALIFIED | No production deployment, automatic evidence service, remote GPU worker, general image-editing provider, energy attribution or subjective image quality judgement is claimed. |
